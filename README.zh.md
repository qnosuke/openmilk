# openmilk 🥛

一款完全在浏览器中运行的任务管理 Web 应用，目标是成为 Remember The Milk 的替代品（开发中）。

- 无需服务器，零运行成本（仅靠静态托管即可运行）
- 数据保存在浏览器内（IndexedDB），内置 JSON 备份/恢复
- UI 支持日本語 / English / 中文
- 设计上便于 AI 代理（OpenClaw 等）通过文件和 URL 进行操作

**第一次使用？请阅读[使用手册](./MANUAL.zh.md)**（[日本語](./MANUAL.md) / [English](./MANUAL.en.md)）

## 开发

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run check    # 类型检查（svelte-check + tsc）
npm run test     # 单元测试
npm run build    # 生产构建 (dist/)
```

## 快速添加语法

```
明天提交报告 30分钟 !2 #工作
```

无论以空格分隔还是嵌在词语中都能解析（支持日 / 英 / 中输入）:

- 期限: `明日` `明天` `tomorrow` `金曜` `周三` `next fri` `9/15` `9月15日` `2026-10-01`
- 时间: `10時` `午後3時` `9:30` `2pm` `10点` — 可以与日期同时使用（如「明天10点」）
  （只有时间没有日期时按「今天」处理）
- 预估用时: `30分` `2時間` `1時間半` `45min` `1h30min` `1h30m` `0.5h` `30m` `2小时` `30分钟`
- 优先级: `!1`（高）`!2` `!3`
- 标签: `#购物`（可多个）

## 功能

- 通过侧边栏切换列表。任务会被添加到当前显示的列表中，先在 INBOX 收集，之后再整理
  （列表也可以删除，其中的任务不会丢失，而是回到 INBOX）
- 可切换排序方式（按期限 / 按优先级 / 按添加顺序），选择会被保存
- 点击任务名可进行详细编辑（备注、期限、优先级、列表、预估用时、标签）
- 显示今天及更早到期的未完成任务的预估用时合计（作为今天工作量的参考）

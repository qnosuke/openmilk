# openmilk 操作スキル

openmilk（ブラウザ駐在型タスク管理アプリ）をエージェントから操作するための手順。
このアプリは「エージェントがタスクを整理し、人間はビューワーとして確認・微調整する」
使い方を想定して設計されている。

- アプリ URL: 環境設定 `OPENMILK_URL`（未設定なら `http://localhost:5173`）
- 操作は基本ブラウザ自動化で行う。UI は正しい HTML 要素と aria-label で構成されており、
  DOM スナップショットから確実に操作できる

## 1. タスクを追加（最もよく使う操作）

`{OPENMILK_URL}/?add=<URLエンコードした1行>` をブラウザで開くだけで登録される。
（アプリ側で即座に保存され、URL パラメータは自動で消える。1 タスク = 1 URL）

記法（日/英/中どれでも可、スペースがなくても解析される）:

```
明日レポート提出 30分 !2 #仕事
```

- 期限: `今日` `明日` `明後日` `金曜` `来週月曜` `9/15` `9月15日` `2026-10-01`
  / `today` `tomorrow` `next fri` / `今天` `明天` `下周三`
- 時刻: `10時` `10時半` `午後3時` / `9:30` `2pm` / `10点` `下午3点`。
  「明日10時」のように日付と併用可。日付なしで時刻だけ書くと「今日」の予定になる
- 見積もり: `30分` `2時間` `1時間半` / `45min` `0.5h` / `2小时` `30分钟`
- 優先度: `!1`（高）`!2` `!3` / タグ: `#タグ名`（複数可）
- 解析できなかった語はタイトルに残るので、失敗しても情報は失われない

## 2. タスクを読む

- **一覧の確認**: ページを開いて DOM を読む。サイドバーに すべて/INBOX/各リストの
  ボタン（件数つき）、各行にタスク名・優先度・期限・タグが出る
- **完全なデータが欲しいとき**: 「書き出し」ボタンを押すと
  `openmilk-backup-YYYY-MM-DD.json` がダウンロードされる（全タスク・全リスト、
  論理削除済みも含む）

## 3. 完了・削除・編集

- 完了: checkbox の aria-label `「{タイトル}」を完了にする`
- 削除: button `「{タイトル}」を削除`（論理削除。実データは残る）
- 詳細編集: button `「{タイトル}」の詳細を編集` でダイアログを開き、
  メモ/期限/優先度/リスト/見積もり/タグを変更して「保存」

UI 言語（サイドバー下の「言語」）が English / 中文 の場合、ラベルは各言語になる
（Complete / Delete / Edit、完成 / 删除 / 编辑 など）。迷ったらまず言語を確認。

## 4. リストの管理

- 作成: 「新しいリスト」input に名前を入れて Enter → 作成したリストに自動で切り替わる。
  以降の `?add=` やフォーム追加はそのリストに入る
- 切替: サイドバーの nav ボタン（すべて / INBOX / 各リスト）
- 削除: `リスト「{名前}」を削除` ボタン。**タスクは消えず INBOX に戻る**

## 5. バックアップと復元

- 書き出し: 「書き出し」→ JSON ダウンロード。人間に見せるときもこれ
- 復元・統合: 「読み込み」で JSON を投入。**冪等マージ**（同じ id は updatedAt の
  新しい方が勝つ）なので、空からの復元でも既存データとの統合でも安全

## 注意事項

- `?add=` は表示中のリスト（または INBOX）に入る。特定リストに入れたいときは
  先にそのリストへ切り替えてから URL を開く
- **リトライ冪等性**: 同じ `?add=` の1行は 10 分以内の再実行ではスキップされる
  （ゲートウェイ再起動などの自動リトライで重複登録されない）。別のタスクとして
  同じ1行を素早く入れたい場合は、文中の語を1つ変えるか、UI のフォームから入れる
- DOM 操作のたびに snapshot は取り直すこと（古い ref は無効になる）
- アプリが起動していない場合は、リポジトリで `npm run dev`（ポート 5173）。
  勝手に起動してよいか不明ならユーザーに確認
